Intent Check — demo scenarios

Static pages that simulate common phishing patterns. Use to test the extension end-to-end without finding malicious sites in the wild.

  • 1. Hidden approval ("free mint" drainer)

    Page styled like an NFT mint, button actually triggers USDC.approve(0xdEaD…, MAX_UINT256) on Base. The deterministic UNLIMITED_APPROVAL finding should fire and force DANGER.

    Open fake-mint demo →

  • 2. Permit2 batch drainer

    Page styled like an airdrop claim, asks for an eth_signTypedData_v4 Permit2 batch transfer authorization to an unknown spender across multiple stablecoins. The PERMIT2_SPENDER_UNKNOWN finding should fire.

    Open airdrop-claim demo →

  • 3. Lookalike origin (origin-trust check)

    This file would normally live on a fake hostname like app.unisvvap.org. To simulate, host this folder on a typo-domain (or use Chrome's "Override host" devtools) and trigger any wallet request. The LOOKALIKE_DOMAIN finding should fire.

    No standalone HTML — re-open #1 or #2 from a typo domain.

Open chrome://extensions, ensure Intent Check is loaded unpacked from apps/extension/dist, then connect a (test) wallet on Base or Optimism and trigger the buttons above.
